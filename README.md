## Run Locally

Clone the project

```bash
  git clone https://github.com/vantern-org/nobg.git
```

Go to the project directory

```bash
  cd nobg
```

Install dependencies

```bash
  pnpm install
```

Start the server

```bash
  pnpm run start
```
